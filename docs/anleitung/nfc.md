# moto NFC Ergänzung

Diese Ergänzung beschreibt nur die Vorbereitung in moto für Einrichtungen, die zusätzlich NFC-Tablets nutzen.

## 1. Kinder zuerst in moto anlegen

Bevor ein NFC-Armband zugewiesen werden kann, muss das Kind in moto vorhanden sein.

1. Legen Sie das Kind manuell an oder importieren Sie die Kinder per Excel oder CSV.
2. Prüfen Sie Vorname, Nachname und Klasse.
3. Prüfen Sie die OGS Gruppe.
4. Prüfen Sie, ob das Kind unter `Alle Kinder` gefunden wird.

## 2. Räume klar benennen

Räume sollten eindeutig benannt sein.

Gute Beispiele:

- Gruppenraum Blau
- Mensa
- Turnhalle
- Schulhof
- Kreativraum

Vermeiden Sie unklare Namen wie:

- Raum 1
- Neu
- Test

## 3. Gruppen vorbereiten

1. Öffnen Sie `Datenverwaltung`.
2. Öffnen Sie `Gruppen`.
3. Legen Sie die benötigten Gruppen an.
4. Ordnen Sie bei Bedarf einen `Gruppenraum` zu.
5. Ordnen Sie bei Bedarf eine `Gruppenleitung` zu.

## 4. Aktivitäten für das Tablet vorbereiten

Aktivitäten sollten kurz und verständlich benannt sein, weil sie später schnell ausgewählt werden müssen.

1. Öffnen Sie `Datenverwaltung`.
2. Öffnen Sie `Aktivitäten`.
3. Legen Sie die benötigten Aktivitäten an.
4. Verwenden Sie klare Namen.
5. Wählen Sie eine passende Kategorie.
6. Tragen Sie `Maximale Teilnehmer` ein.
7. Speichern Sie die Aktivität.

Gute Beispiele:

- Freispiel
- Hausaufgaben
- Mensa
- Schulhof
- Basteln
- Fußball

## 5. Vor dem Tablet-Einsatz prüfen

Prüfen Sie in moto:

- Alle Kinder sind angelegt.
- Alle benötigten Gruppen sind angelegt.
- Alle wichtigen Räume sind angelegt.
- Die benötigten Aktivitäten sind angelegt.
- Mitarbeitende können sich anmelden.
- Unter `Alle Kinder` sind die Kinder auffindbar.

## 6. Hinweise aus der Tablet-Anleitung

Für moto sind vor allem diese Punkte wichtig:

- NFC-Armbänder enthalten keine Namen und keine persönlichen Daten.
- Ein Armband kann erst sinnvoll zugewiesen werden, wenn das Kind in moto angelegt ist.
- Die Namen von Aktivitäten und Räumen sollten im Alltag sofort verständlich sein.
- Wenn ein Kind nicht gefunden wird, zuerst in moto prüfen, ob es angelegt ist.
