# moto Standard

Diese Anleitung erklärt die Einrichtung und Nutzung von moto ohne NFC-Tablet.

## 1. Erste Schritte

Starten Sie mit diesen Schritten. Danach ist moto so vorbereitet, dass der OGS-Alltag geplant und dokumentiert werden kann.

### 1.1 Konto erstellen und anmelden

1. Öffnen Sie die Einladungs-Mail von moto.
2. Folgen Sie dem Link in der E-Mail.
3. Erstellen Sie Ihr Konto.
4. Öffnen Sie moto.
5. Geben Sie Ihre `E-Mail-Adresse` ein.
6. Geben Sie Ihr `Passwort` ein.
7. Klicken Sie auf `Anmelden`.

Falls Sie Ihr Passwort nicht kennen, klicken Sie auf `Passwort vergessen?`.

Checkliste:

- Das Konto wurde erstellt.
- Die Anmeldung funktioniert.
- Die Startseite von moto ist sichtbar.

### 1.2 Orientierung in der Navigation

Die wichtigsten Bereiche sind:

- `Home`
- `Alle Kinder`
- `Aktivitäten`
- `Räume`
- `Mitarbeiter`
- `Vertretungen`
- `Stundenplan`
- `Zeiterfassung`
- `Einstellungen`
- `Datenverwaltung`
- `Anmeldungen`

Beginnen Sie in der `Datenverwaltung`. Dort werden Kinder, Personal, Räume, Gruppen und Aktivitäten gepflegt.

### 1.3 Kinder anlegen

Sie können Kinder einzeln anlegen oder mehrere Kinder per Excel oder CSV importieren.

Manuell anlegen:

1. Öffnen Sie `Datenverwaltung`.
2. Öffnen Sie `Kinder`.
3. Legen Sie ein neues Kind an.
4. Füllen Sie den Bereich `Persönliche Daten` aus.
5. Tragen Sie `Vorname`, `Nachname`, `Klasse` und `OGS Gruppe` ein.
6. Füllen Sie den Bereich `Erziehungsberechtigte` aus.
7. Tragen Sie `Name des Erziehungsberechtigten` ein.
8. Tragen Sie bei `Kontakt des Erziehungsberechtigten` eine E-Mail-Adresse oder Telefonnummer ein.
9. Aktivieren Sie `Fährt mit dem Bus`, falls das Kind mit dem Bus fährt.
10. Tragen Sie bei Bedarf `Zusätzliche Informationen` ein.
11. Aktivieren Sie `Datenschutzeinwilligung erteilt`, wenn die Einwilligung vorliegt.
12. Speichern Sie das Kind.

Per Excel oder CSV importieren:

1. Öffnen Sie `Datenverwaltung`.
2. Öffnen Sie `Kinder`.
3. Klicken Sie auf `Importieren`.
4. Wählen Sie `Excel (.xlsx)` oder `CSV (Komma-getrennt)`.
5. Klicken Sie auf `Vorlage herunterladen`.
6. Füllen Sie die Vorlage aus.
7. Speichern Sie die Datei.
8. Ziehen Sie die Datei in den Bereich `Datei hochladen` oder wählen Sie die Datei aus.
9. Prüfen Sie die `Datenvorschau`.
10. Korrigieren Sie Fehler in der Datei, falls Fehler angezeigt werden.
11. Laden Sie die korrigierte Datei erneut hoch.
12. Klicken Sie auf `Schüler importieren`.

Geburtstage können in diesen Formaten eingetragen werden:

- `JJJJ-MM-TT`
- `TT.MM.JJJJ`
- `TT.MM.JJ`

Hinweise:

- Die `OGS Gruppe` muss vorhanden sein, bevor sie beim Kind ausgewählt werden kann.
- Datenschutzangaben sollten nur gesetzt werden, wenn sie wirklich vorliegen.
- Importieren Sie am besten zuerst eine kleine Testdatei mit wenigen Kindern.

### 1.4 Mitarbeitende anlegen

1. Öffnen Sie `Datenverwaltung`.
2. Öffnen Sie `Personal`.
3. Legen Sie eine neue Person an.
4. Tragen Sie `Vorname` und `Nachname` ein.
5. Tragen Sie die `E-Mail` ein.
6. Ergänzen Sie bei Bedarf den `Geburtstag`.
7. Tragen Sie im Bereich `Berufliche Informationen` das `Fachgebiet` ein.
8. Tragen Sie bei Bedarf `Rolle`, `Qualifikationen` und `Interne Notizen` ein.
9. Vergeben Sie ein `Temporäres Passwort`, wenn dieses Feld angezeigt wird.
10. Speichern Sie die Person.

Die E-Mail-Adresse wird für die Anmeldung verwendet.

### 1.5 Räume anlegen

1. Öffnen Sie `Datenverwaltung`.
2. Öffnen Sie `Räume`.
3. Legen Sie einen neuen Raum an.
4. Tragen Sie den `Raumname` ein.
5. Wählen Sie eine `Kategorie`.
6. Tragen Sie bei Bedarf `Gebäude` ein.
7. Tragen Sie bei Bedarf `Etage` ein.
8. Wählen Sie eine `Farbe`.
9. Speichern Sie den Raum.

Mögliche Kategorien sind:

- `Normaler Raum`
- `Gruppenraum`
- `Themenraum`
- `Sport`

Eine klare Raumbenennung hilft später unter `Alle Kinder`, in der aktuellen Aufsicht und im Stundenplan.

### 1.6 Gruppen anlegen

1. Öffnen Sie `Datenverwaltung`.
2. Öffnen Sie `Gruppen`.
3. Legen Sie eine neue Gruppe an.
4. Tragen Sie den `Gruppenname` ein.
5. Wählen Sie bei Bedarf einen `Gruppenraum`.
6. Wählen Sie bei Bedarf eine oder mehrere Personen als `Gruppenleitung`.
7. Speichern Sie die Gruppe.

Gruppen helfen beim Filtern, bei Zuständigkeiten und bei der Übersicht im Alltag.

### 1.7 Aktivitäten anlegen

1. Öffnen Sie `Datenverwaltung`.
2. Öffnen Sie `Aktivitäten`.
3. Legen Sie eine neue Aktivität an.
4. Tragen Sie den `Name` ein.
5. Wählen Sie eine `Kategorie`.
6. Tragen Sie `Maximale Teilnehmer` ein.
7. Wählen Sie bei Bedarf einen `Hauptbetreuer`.
8. Speichern Sie die Aktivität.

Aktivitäten können später im `Stundenplan` genutzt oder bei einer spontanen Aktivität ausgewählt werden.

## 2. Im OGS-Alltag

Diese Kapitel sind für den täglichen Betrieb gedacht. Sie helfen beim Suchen, Einchecken, Beaufsichtigen und Dokumentieren.

### 2.1 Alle Kinder

1. Öffnen Sie `Alle Kinder`.
2. Suchen Sie nach dem Namen des Kindes.
3. Nutzen Sie bei Bedarf die Filter.
4. Öffnen Sie das Kind, um Details zu sehen.

Unter `Alle Kinder` sehen Sie je nach Einrichtung unter anderem:

- Anwesenheitsstatus
- Raum oder Aktivität
- Gruppe
- Klasse
- Ankunftszeit
- Abholzeit
- Hinweise wie krank oder entschuldigt

### 2.2 Aktuelle Aufsicht nutzen

1. Öffnen Sie die aktuelle Aufsicht.
2. Prüfen Sie den Bereich `Jetzt geplant`.
3. Wählen Sie den Raum oder die laufende Aktivität aus.
4. Prüfen Sie die Kinderliste.
5. Klicken Sie bei erwarteten Kindern auf `Einchecken`.
6. Klicken Sie bei anwesenden Kindern auf `Raum verlassen`, wenn das Kind die Aktivität verlässt.
7. Markieren Sie erwartete Kinder bei Bedarf als `Entschuldigt` oder `Abwesend`.
8. Klicken Sie auf `Zurück auf erwartet`, wenn eine Markierung korrigiert werden soll.
9. Nutzen Sie `Weiteren Schüler suchen...`, um ein ungeplantes Kind hinzuzufügen.
10. Klicken Sie auf `Beenden`, wenn die Aktivität abgeschlossen ist.

Typische Bereiche in einer laufenden Aktivität:

- `Anwesend`
- `Erwartet`
- `Abwesend`

### 2.3 Spontane Aktivität starten

1. Öffnen Sie die aktuelle Aufsicht.
2. Klicken Sie auf `Spontane Aktivität starten`.
3. Geben Sie bei `Aktivität` den Namen ein oder wählen Sie eine vorgeschlagene Aktivität.
4. Wählen Sie bei `Raum` einen freien Raum aus.
5. Wählen Sie bei Bedarf `Weitere Betreuer`.
6. Klicken Sie auf `Aktivität starten`.
7. Fügen Sie Kinder hinzu.
8. Beenden Sie die Aktivität mit `Beenden`.

Wenn ein Raum bereits belegt ist, kann er nicht erneut für eine spontane Aktivität ausgewählt werden.

### 2.4 Räume im Alltag ansehen

1. Öffnen Sie `Räume`.
2. Nutzen Sie die Suche `Raum suchen...`, falls die Liste lang ist.
3. Filtern Sie bei Bedarf nach `Gebäude`.
4. Filtern Sie bei Bedarf nach `Status`.
5. Öffnen Sie einen Raum, um Details zu sehen.

Die Raumkarten zeigen:

- `Frei` oder `Belegt`
- aktuelle Gruppe oder Aktivität
- Anzahl der Kinder
- zuständige Aufsicht
- Kapazität, falls gepflegt

Wenn Kinder ohne Raumzuweisung unterwegs sind, erscheint der Bereich `Unterwegs`. Über `Zuweisen` können diese Kinder einem Raum zugeordnet werden.

### 2.5 Mitarbeiter ansehen

1. Öffnen Sie `Mitarbeiter`.
2. Suchen Sie nach Namen.
3. Nutzen Sie den Filter `Status`.
4. Wählen Sie bei Bedarf `Alle`, `Anwesend`, `Abwesend`, `Im Raum`, `Homeoffice` oder `Krank/Urlaub`.

Die Mitarbeiterübersicht hilft dabei, Anwesenheit und Zuständigkeiten im Blick zu behalten.

### 2.6 Vertretungen verwalten

1. Öffnen Sie `Vertretungen`.
2. Suchen Sie bei Bedarf mit `Fachkraft suchen...`.
3. Nutzen Sie den Statusfilter `Alle`, `Verfügbar` oder `In Vertretung`.
4. Wählen Sie eine verfügbare pädagogische Fachkraft aus.
5. Wählen Sie im Dialog `Vertretung zuweisen` eine `OGS-Gruppe` aus.
6. Legen Sie die `Anzahl der Tage` fest.
7. Klicken Sie auf `Zuweisen`.

Aktive Einträge erscheinen in den Bereichen:

- `Tagesübergaben`
- `Vertretungen`

Mit `Beenden` kann eine Vertretung wieder beendet werden.

### 2.7 Zeiterfassung nutzen

1. Öffnen Sie `Zeiterfassung`.
2. Wählen Sie `In der OGS` oder `Homeoffice`.
3. Klicken Sie auf `Einstempeln`.
4. Starten Sie bei Bedarf eine Pause.
5. Beenden Sie die Pause.
6. Klicken Sie am Ende der Arbeitszeit auf `Ausstempeln`.

Abwesenheit melden:

1. Klicken Sie auf `Abwesenheit melden`.
2. Wählen Sie die `Art der Abwesenheit`.
3. Wählen Sie den Zeitraum.
4. Klicken Sie auf `Speichern`.

Mögliche Abwesenheitsarten sind:

- `Krank`
- `Urlaub`

Die Zeiterfassung kann Hinweise zu langen Arbeitszeiten, Pausen oder fehlenden Zeiten anzeigen. Prüfen Sie solche Hinweise direkt.

## 3. Planung

### 3.1 Stundenplan nutzen

Der Bereich `Stundenplan` dient zur Planung von Betreuungszeiten, Aktivitäten, Personal und erwarteten Kindern.

1. Öffnen Sie `Stundenplan`.
2. Wählen Sie eine Planungsperiode aus.
3. Wechseln Sie bei Bedarf zwischen Monat, Woche, Jahr und Serien.
4. Klicken Sie auf `Termin`.
5. Legen Sie einen einmaligen oder wiederkehrenden Termin an.
6. Tragen Sie Zeit, Raum, Kinder und Personal ein.
7. Klicken Sie auf `Speichern`.
8. Nutzen Sie bei wiederkehrenden Terminen `Termine erzeugen`.
9. Klicken Sie einen Termin im Kalender an, um Details zu öffnen.
10. Starten, beenden oder bearbeiten Sie den Termin aus der Detailansicht.

Begriffe:

- Ein Termin ist ein konkreter Eintrag im Kalender.
- Eine Serie ist ein wiederkehrender Termin.
- Eine Planungsperiode ist der Zeitraum, in dem geplant wird, zum Beispiel ein Schuljahr.

Planungsoptionen:

- `Lücken füllen` legt fehlende Termine aus Serien an.
- `Woche neu berechnen` berechnet die gewählte Woche neu.

### 3.2 Geplante Aktivität aus dem Stundenplan starten

1. Öffnen Sie `Stundenplan`.
2. Öffnen Sie den geplanten Termin.
3. Prüfen Sie `Details`, `Personal` und `Kinder`.
4. Klicken Sie auf `Jetzt starten`, wenn die Aktivität beginnen soll.
5. Nutzen Sie danach die aktuelle Aufsicht für die Kinderliste.
6. Klicken Sie auf `Beenden`, wenn die Aktivität abgeschlossen ist.

## 4. Kinderakten und Verläufe

### 4.1 Kinderdetail öffnen

1. Öffnen Sie `Alle Kinder` oder `Datenverwaltung`.
2. Öffnen Sie das gewünschte Kind.
3. Wechseln Sie zwischen den Tabs.

Wichtige Tabs:

- `Stammdaten`
- `Erziehungsberechtigte`
- `Betreuungszeiten`
- `Historie`

Wenn kein Kind ausgewählt ist, zeigt moto `Keinen Schüler ausgewählt`.

### 4.2 Stammdaten bearbeiten

1. Öffnen Sie den Tab `Stammdaten`.
2. Prüfen Sie die persönlichen Daten.
3. Bearbeiten Sie bei Bedarf Klasse, Gruppe, Buskind, Hinweise oder Datenschutzangaben.
4. Klicken Sie auf `Speichern`.

### 4.3 Betreuungszeiten pflegen

Im Tab `Betreuungszeiten` können regelmäßige Zeiten gepflegt werden.

Ankunftsplan:

1. Öffnen Sie den Ankunftsbereich.
2. Klicken Sie auf `Bearbeiten`.
3. Tragen Sie die Uhrzeiten im Format `HH:MM` ein.
4. Ergänzen Sie bei Bedarf `Besonderheiten...`.
5. Speichern Sie den Plan.

Abholplan:

1. Öffnen Sie den Abholbereich.
2. Klicken Sie auf `Bearbeiten`.
3. Tragen Sie die Uhrzeiten im Format `HH:MM` ein.
4. Ergänzen Sie bei Bedarf `Abholer, Besonderheiten...`.
5. Speichern Sie den Plan.

Einzelne Tage können über `Tag bearbeiten` angepasst werden.

### 4.4 Historien prüfen

Je nach freigeschalteter Funktion können diese Verläufe sichtbar sein:

- `Anwesenheits-Historie`
- `Anwesenheitsprotokoll`
- `Mensaverlauf`

## 5. Anmeldungen

Der Bereich `Anmeldungen` besteht aus vier Seiten:

- `Überblick`
- `Anmeldephasen`
- `Betreuungsangebote`
- `Anmeldeformulare`

### 5.1 Überblick nutzen

1. Öffnen Sie `Anmeldungen`.
2. Öffnen Sie `Überblick`.
3. Prüfen Sie die aktiven Phasen und eingegangenen Anmeldungen.
4. Öffnen Sie eine Anmeldung, um Details zu prüfen.
5. Treffen Sie eine Entscheidung.

Je nach Einrichtung stehen Entscheidungen wie Genehmigen, Ablehnen oder Warteliste zur Verfügung.

### 5.2 Anmeldephase anlegen

1. Öffnen Sie `Anmeldephasen`.
2. Legen Sie eine neue Phase an.
3. Wählen Sie die Art: `Schuljahr`, `Ferienbetreuung` oder `Sonstiges`.
4. Tragen Sie den Betreuungszeitraum ein.
5. Tragen Sie den Anmeldezeitraum ein.
6. Weisen Sie bei Bedarf ein Formular zu.
7. Legen Sie fest, wie mit vollen Angeboten umgegangen wird.
8. Aktivieren Sie die Phase.
9. Speichern Sie die Phase.

### 5.3 Betreuungsangebote anlegen

1. Öffnen Sie `Betreuungsangebote`.
2. Wählen Sie die passende Anmeldephase aus.
3. Legen Sie ein neues Betreuungsangebot an.
4. Tragen Sie Name und Beschreibung ein.
5. Wählen Sie die Wochentage.
6. Aktivieren Sie bei Bedarf Ferienbetreuung oder Mittagessen.
7. Tragen Sie bei Bedarf Kapazität und Preis ein.
8. Speichern Sie das Angebot.

Wenn kein Preis gepflegt ist, kann das Angebot als `Ohne Preis` angezeigt werden.

### 5.4 Anmeldeformular bearbeiten

1. Öffnen Sie `Anmeldeformulare`.
2. Öffnen Sie eine Formularvorlage oder legen Sie eine neue Vorlage an.
3. Prüfen Sie die festen Pflichtfelder.
4. Fügen Sie bei Bedarf eigene Felder hinzu.
5. Speichern Sie das Formular.
6. Prüfen Sie die Vorschau.

Feste Pflichtfelder sind unter anderem:

- Vorname des Elternteils
- Nachname des Elternteils
- E-Mail des Elternteils
- Telefonnummer des Elternteils
- Vorname des Kindes
- Nachname des Kindes
- Geburtsdatum des Kindes
- Klassenstufe des Kindes

Mögliche Feldtypen sind:

- `Ja/Nein`
- `Zahl`
- `Text`
- `Mehrzeiliger Text`
- `Datum`
- `Auswahl`
- `Telefonliste`
- `Wochenzeiten`
- `Kontaktliste`

### 5.5 Öffentliche Anmeldung testen

Die öffentliche Anmeldung führt Eltern durch diese Schritte:

- `Auswahl`
- `Formular`
- `Bestätigung`

Prüfen Sie vor dem Teilen des Links:

- Die richtige Phase ist aktiv.
- Die richtigen Angebote sind sichtbar.
- Das Formular enthält alle nötigen Felder.
- Die Bestätigung ist verständlich.
- Die Anmeldung erscheint danach im Überblick.

## 6. Weitere Funktionen und Einstellungen

### 6.1 Datenverwaltung Übersicht

Die `Datenverwaltung` enthält diese Bereiche:

- `Kinder`: Kinderdaten verwalten und bearbeiten
- `Personal`: Personaldaten und Zuordnungen verwalten
- `Räume`: Räume und Ausstattung verwalten
- `Aktivitäten`: Aktivitäten und Zeitpläne verwalten
- `Gruppen`: Gruppen und Kombinationen verwalten
- `Rollen`: Benutzerrollen und Berechtigungen verwalten
- `Geräte`: Terminals und IoT-Geräte verwalten
- `Berechtigungen`: Systemberechtigungen ansehen

Nutzen Sie den Button `Verwalten`, um einen Bereich zu öffnen.

### 6.2 Rollen und Berechtigungen

`Rollen` legen fest, welche Aufgaben eine Person in moto ausführen darf.

Wichtige Felder:

- `Name`
- `Beschreibung`
- `Systemrolle`
- `Berechtigungen`

`Berechtigungen` zeigen genauer, welche Aktionen erlaubt sind. Ändern Sie Rollen nur, wenn klar ist, welche Personen dadurch Zugriff bekommen oder verlieren.

### 6.3 Geräte

Der Bereich `Geräte` ist vor allem relevant, wenn Terminals oder Tablets verwaltet werden.

Wichtige Felder:

- `Geräte-ID`
- `Gerätetyp`
- `Gerätename`
- `Verbindung`
- `Letzter Standort`
- `Status`
- `API-Schlüssel`

Statuswerte können unter anderem `Aktiv`, `Inaktiv`, `Wartung` oder `Offline` sein.

### 6.4 Einstellungen prüfen

1. Öffnen Sie `Einstellungen`.
2. Öffnen Sie den passenden Bereich.
3. Ändern Sie nur Einstellungen, deren Auswirkung klar ist.
4. Speichern Sie Änderungen direkt in der jeweiligen Einstellung.

Wichtige Bereiche:

- `Betrieb`
- `Datenschutz`
- `Geräte`
- `Anmeldung`
- `System`
- `Allgemein`

### 6.5 Profil bearbeiten

1. Öffnen Sie `Profil`.
2. Klicken Sie auf `Bearbeiten`.
3. Ändern Sie `Vorname` oder `Nachname`.
4. Klicken Sie auf `Speichern`.

Das Feld `E-Mail` ist gesperrt, weil es für die Anmeldung verwendet wird.

Profilbild ändern:

1. Klicken Sie auf `Profilbild ändern`.
2. Wählen Sie ein Bild aus.
3. Warten Sie auf die Bestätigung.

Passwort ändern:

1. Klicken Sie auf `Passwort ändern`.
2. Tragen Sie die geforderten Angaben ein.
3. Speichern Sie das neue Passwort.

## 7. Was zuerst fertig sein sollte

Vor dem ersten vollständigen Nutzungstag sollten diese Punkte erledigt sein:

- Alle Kinder sind angelegt oder importiert.
- Die wichtigsten Mitarbeitenden sind angelegt.
- Die Anmeldung der Mitarbeitenden wurde getestet.
- Räume sind angelegt.
- Gruppen sind angelegt.
- Kinder sind den richtigen Gruppen zugeordnet.
- Aktivitäten sind angelegt, wenn sie im Stundenplan oder spontan genutzt werden.
- Der Stundenplan ist für die erste Woche geprüft.
- Eine Testanmeldung wurde geprüft, falls die Online-Anmeldung genutzt wird.
- Die Zeiterfassung wurde einmal getestet.
