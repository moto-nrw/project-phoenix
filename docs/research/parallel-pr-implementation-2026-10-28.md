## Acceptance checklist

- [ ] Screenshots: genuinely parallel capture and image processing; identical
  complete shot/device/output set, deterministic manifest, isolated sessions,
  bounded work, quality failures and atomic publication preserved. Record a
  comparable execution measurement, not an inferred speedup.
- [ ] Classify every shared artifact and migrate its producers and consumers:
  authored source, pure derivative, reviewed expectation, measured evidence.
- [ ] Error registry: automatically discovered domain fragments; globally
  unique codes/legacy identities/symbols; stable output partitions; every
  current wire code, class and interpolation parameter unchanged; stale output
  check and source-size limits preserved; mechanical regeneration after merge.
- [ ] Bundle guard: observations become CI artifacts, approved budgets remain
  independent policy; reusable SHA/toolchain/config-bound base measurements;
  no extra complete base build for each PR, cumulative-growth protection,
  improvements do not require observation-baseline commits.
- [ ] Architecture registers: owner-specific reviewed intent separated from
  observed bindings; full immutable-base, digest, stale/unknown and global
  dependency/ownership checks preserved across the format migration.
- [ ] Router and middleware goldens: stable resource fragments; complete
  production-router/security/module assertions and runtime RouteCatalog
  embedding preserved; no automatic approval of observed behavior.
- [ ] Proxy route expectations and query budgets: stable capability fragments,
  independent discovery/global completeness/uniqueness and shrink-only budget
  validation preserved.
- [ ] Help and translations: topic/namespace sources, automatic composition,
  unchanged public lookup interfaces and user-visible content; duplicate IDs
  and locale parity remain globally enforced.
- [ ] All direct consumers, generated-file checks, CI path selection, tooling
  and current documentation use the new canonical sources.
- [ ] Relevant behavior/regression tests, frontend zero-warning check, backend
  lint/architecture/fixture guards, affected closure, document checks and final
  review completed. Failed or blocked checks recorded explicitly.
