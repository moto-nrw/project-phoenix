# Domain documentation

This repository has one domain context: read `CONTEXT.md` at the root and the
relevant decisions in `docs/adr/` before exploring or changing a domain.

Use the glossary's terms in code, tests, issues and explanations. Check an
unfamiliar term against the glossary before inventing a synonym. Surface a
conflict with an existing ADR, with the concrete scenario, instead of silently
overriding the decision.
